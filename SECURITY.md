# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **security@payriff.com** instead, with:

- the SDK and version you are using,
- a description of the issue and its impact,
- steps or a minimal code sample that reproduces it.

Never include real card numbers, CVVs, app keys or other production secrets in a report. Use
placeholders or test values.

We will confirm that we received your report and keep you informed while we investigate and fix
it. Please give us a reasonable time to release a fix before disclosing the issue publicly.

This address also covers vulnerabilities in the Payriff API itself, not only in this SDK.

## Supported versions

Security fixes are released for the latest published version of the SDK. Upgrade to it before
reporting a problem.
